# ノッポンズ

深夜ラジオ局「FMよふけ」の電波から生まれた13人のキャラクターをステージに並べて、リズム・ベース・メロディ・ボイスを重ねて曲を作る、スマホ横画面向けの音楽ゲームです。
13人目の「ザザ」をステージに乗せるか「変身」ボタンを押すと、昼の公開録音ステージが放送事故の夜に変わり、全員がホラー風の姿と音になります。

- HTML 1枚と音声ファイルだけで動きます(ビルド不要・外部ライブラリなし)
- 各キャラの設定は、ゲーム内の「図鑑」から読めます

## 遊び方

| 操作 | 内容 |
|---|---|
| 下のキャラをステージへドラッグ(またはタップ) | そのキャラが歌い始めます。次の小節の頭から入るので、リズムがずれません |
| ステージのキャラをタップ | ミュート/解除 |
| × ボタン | ステージから外す |
| リズム・ベース・メロディ・ボイスを1人ずつそろえる | コンボ演出(電飾が拍に合わせて光ります) |
| ザザを乗せる/「変身」ボタン | 変身モード。ザザを外すか「もどる」で元に戻ります |
| 全画面 | 全画面表示の切り替え(iPhone の Safari は非対応。「ホーム画面に追加」で全画面になります) |
| おまかせ | ランダムな編成 |

## ローカルで動かす

音声ファイルを `fetch` で読み込むため、`index.html` をダブルクリックで開くだけでは音が鳴りません。簡単なサーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push します
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存します
3. 表示された URL を開きます。音はスマホでも、最初にどこかをタップしたあとに鳴り始めます

## ファイル構成

```
index.html              ゲーム本体(キャラの絵・背景・再生エンジン・口パクのタイミングを含む)
audio/
  r1_n.mp3 … x1_n.mp3   通常版のループ(13本)
  r1_h.mp3 … x1_h.mp3   変身版のループ(13本)
  drone_h.mp3           変身中の環境音ループ(砂嵐・ハム・風)
  sting_on.mp3          変身するときの効果音
  sting_off.mp3         元に戻るときの効果音

  render.html           曲を合成するシンセ(Web Audio)。書き出し専用
```

## 音声ファイルの仕様

すべてのループは次の形式です。自分で録った素材に差し替えるときもこれに合わせてください。

- 120 BPM・4小節(16分音符 × 64 = ちょうど 8 秒)、ニ長調の王道進行(G△7 → A7 → F#m7 → Bm7)
- ループ本体の前後に 0.25 秒ずつ、ループの続き(前はループ末尾、後ろはループ先頭)を余白として入れる。ファイル全体の長さは 8.5 秒
- モノラル、48 kHz、MP3 80 kbps。パートごとに音量をそろえて書き出しています

前後の余白は、MP3 の頭に入る無音で継ぎ目が切れないようにするためのものです。ゲームは余白の内側だけをループ再生します。

## 音を作り直す

合成音を調整して書き出し直す場合の手順です。Python 3、[Playwright](https://playwright.dev/python/)(Chromium)、ffmpeg(libmp3lame 付き)が必要です。

```sh
pip install playwright
playwright install chromium
python3 tools/render/render.py audio        # 29 本の MP3 と hits.json を書き出す
python3 tools/render/update_hits.py         # 口パクのタイミングを index.html に反映
```

- 48 kHz・120 BPM では 16 分音符がちょうど 6,000 サンプルになるので、ループの継ぎ目がサンプル単位で一致します
- 書き出しの開始位置(`PAD`)は 0.0625 秒にしてあります。2 進数で正確に表せない値(0.05 など)にすると、ループの 1 周目と 2 周目でごく一部の音が 1 サンプルずれ、継ぎ目が一致しなくなります
- 目標音量はパートごとに `render.py` の `TARGET` で調整できます

## 軽さのための工夫

スマホで軽く動くように、毎フレームの処理をほとんど GPU に任せています。手を入れるときは次の点を崩さないようにしてください。

- 背景は動かない絵(`.bg`)と、動く小さな部品(`.fx`)に分かれています。雲やランプなどを背景の SVG の中で動かすと、背景全体が毎フレーム描き直されます
- キャラの揺れ・歌うときの伸び縮み・変身後の震え・小節メーター・電飾は CSS アニメーションです。スクリプトは `align()` でそれらの開始時刻を音声の時計にそろえ、口の開け閉めを 30 Hz で切り替えるだけです
- キャラの SVG の中の要素をアニメーションさせると、毎フレームの再描画が必要になります。動かしたいときは、キャラを包む要素(`.fig` / `.sq`)の transform か opacity で表現してください
